쌀먹지수 시급 산출 방식과 데이터 한계

데이터 정정 · 2026-09-11
이 문서의 시급에는 초기 추정값이 포함되어 있으며, 실측 수익이나 현재 시세로 검증되지 않았습니다. 초기 투표 수에 근거한 신뢰도 표시는 중단했습니다. 변경 내용과 데이터 한계
2026년 9월 11일 정정 · 운영자

현재 시급은 초기 추정값에 제보를 반영한 참고값입니다. 실제 플레이 시간·거래 내역·수수료·캐릭터 조건을 수치별로 확인할 수 있는 원자료는 확보하지 못했습니다. 따라서 실측 평균이나 검증된 수익으로 설명한 기존 문구를 정정합니다.

초기값은 관측 표본이 아닙니다

초기 코드에는 시급과 함께 투표 수·제보 수가 설정되어 있었습니다. 이 숫자를 실제 참여자 수로 해석할 수 없습니다. 초기값의 출처별 URL, 수집일, 측정 조건이 제시되지 않은 상태에서 ‘커뮤니티 합의로 검증되었다’고 설명할 근거도 부족합니다.

기존 게임의 제보 반영 계산

계산에 사용하는 기존 가중치는 저장된 제보 수를 최소 1, 최대 20으로 제한한 값입니다. 일반 제보의 가중치는 1입니다. 초보 또는 고수 제보가 해당 기존 값과 30%를 초과해 차이가 나면 가중치는 0.1이 됩니다. 초보 기존 값이 0인 경우 초보 편차 검사는 적용하지 않습니다.

새 참고값 = 반올림[(기존 참고값 × 기존 가중치 + 제보값 × 제보 가중치) ÷ (기존 가중치 + 제보 가중치)]

예를 들어 기존 참고값이 10,000원, 저장된 제보 수가 100, 새 제보가 12,000원이면 기존 가중치는 20입니다. 계산 결과는 (10,000 × 20 + 12,000) ÷ 21 ≈ 10,095원입니다. 새 제보 비중은 약 4.76%입니다. 제보 수가 100이므로 항상 약 1%씩 반영된다는 과거 설명은 잘못되었습니다.

같은 조건에서 20,000원을 제보하면 편차가 30%를 초과하므로 가중치가 0.1이 되고 새 참고값은 약 10,050원입니다. 이때 새 제보 비중은 0.1 ÷ 20.1 ≈ 0.50%입니다. 가중치 0.1은 최종 반영 비중 1%를 뜻하지 않습니다.

이 방식은 기존 값에서 급격히 벗어나는 제보의 영향을 줄이지만, 기존 추정 자체가 틀렸을 때 정정을 늦출 수도 있습니다. 가중 평균 계산만으로 데이터의 사실 여부나 통계적 정확성이 검증되지는 않습니다.

투표 비율을 신뢰도로 표시하지 않습니다

초기 투표 수가 섞여 있으므로 합계와 찬성 비율을 실제 이용자 수 또는 검증 신뢰도로 표시하지 않습니다. ‘참고값에 동의 / 다른 의견’ 버튼은 의견을 남기는 기능입니다. 찬성이 많아도 실제 거래나 수익을 증명하지 않습니다.

자동 작성 글을 제외합니다

과거 코드가 생성한 일일 글, 신작 예시 글, 원문과 일치하는 초기 예시 글은 표시·인용·집계에서 제외합니다. 원본 DB는 보존합니다. 제외된 원글의 다른 답글은 표시하며, 출처를 확인하지 못한 기존 글은 ‘작성 경로 미확인’으로 표시합니다. 자세한 내용은 데이터 정정 안내에 공개했습니다.

중복 방지와 비교 기록의 한계

브라우저 정보와 로컬 저장소를 이용한 중복 입력 제한은 동일인 여부를 확정하지 못합니다. 캐시 삭제나 기기 변경 등을 완전히 방지한다고 보장할 수 없습니다. 브라우저에 보관하는 과거 값도 전체 이용자에게 공통된 주간 통계가 아니므로 순위·시급의 주간 변동 표시는 중단했습니다.

실측 자료에 필요한 조건

측정일, 게임 버전, 서버, 캐릭터 조건, 활동 내용, 반복 횟수, 실제 소요 시간, 판매 완료 내역, 비용과 수수료를 함께 공개해야 비교 가능한 수익 자료가 됩니다. 현금 매출, 게임 내 화폐, 순수익은 별도로 구분해야 합니다. 현재 이 검증 자료를 확보했다고 주장하지 않습니다.
