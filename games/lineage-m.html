공식 자료에서 확인한 내용

NC가 배포한 리니지M 앱 소개에는 월드 거래소와 무접속 플레이가 안내되어 있습니다. 또한 요일에 따라 구성되는 월드 던전과 여러 월드의 이용자가 참여하는 마스터 던전, 일일 도전 성격의 시련 던전을 서로 다른 콘텐츠로 소개합니다. 다만 앱 소개만으로 물품별 거래 가능 여부, 정산 수수료, 실제 수익을 확인할 수는 없습니다.

기록할 때 달라지는 판단

직접 조작 시간은 사용자의 부담을, 경과 시간은 재화가 쌓인 속도를 보여줍니다. 둘 다 쓸모가 있지만 한쪽을 숨기면 독자가 다른 의미의 시급으로 이해하기 쉽습니다. 무접속 기능을 쓴 기간도 실제 적용 조건과 기록 시작·종료 시각을 적어야 합니다.

월드 던전, 시련 던전, 무접속 활동을 전부 ‘리니지M 사냥’으로 저장하면 날짜에 따라 활동 구성이 바뀌어도 계산기가 같은 그룹으로 합칩니다. 활동 이름에 실제 콘텐츠명을 넣고 요일을 메모하세요. 일일 보상 포함 기록은 해당 보상을 이미 받은 뒤의 반복 기록과 분리합니다. 앱 소개는 이런 구분의 출발점이며, 남은 입장 시간·보상 수령 여부는 측정 당일 게임 화면에서 확인해야 합니다.

획득한 아이템의 거래 가능 여부는 이름만으로 판단하지 않습니다. 자신이 가진 물품의 표시와 등록 화면을 확인하고, 판매 완료 전에는 재고로 둡니다. 성장에 사용한 재화까지 판매했다고 가정하면 같은 시간의 결과가 과장됩니다.

실제로 기록하는 순서

  1. 기록 제목을 ‘리니지M / 서버명 / 실제 던전명’처럼 적습니다. 시련 던전과 무접속 활동은 다른 제목으로 저장하고, 당일 보상을 이미 받았는지 메모합니다.
  2. 무접속 활동은 시작 시각, 다시 확인한 시각, 게임에서 확인 가능한 실제 진행 정보를 따로 적습니다. 중간 종료 시점을 모르면 전 시간을 정상 사냥했다고 추정하지 말고 ‘실제 가동 시간 미확인’으로 남깁니다.
