개인 기록 계산기

입력한 게임·활동명, 날짜, 단위, 금액, 시간, 메모는 브라우저에서 계산합니다. ‘이 브라우저에 기록 저장’을 누르면 localStorage의 ssalmuk_records_v1 항목에 저장합니다. 입력값을 사이트 서버나 Firebase에 전송하지 않습니다. 회원가입, 브라우저 지문 생성, 공개 투표 집계 기능을 사용하지 않습니다.

보관과 삭제

저장 기록은 이용자가 개별 삭제하거나 해당 사이트의 브라우저 저장 데이터를 삭제할 때까지 남을 수 있습니다. 시크릿 모드 종료·기기 변경·브라우저 정리 시 사라질 수 있습니다. CSV로 내려받은 파일은 이용자의 기기에 별도로 저장되며 사이트에서 삭제할 수 없습니다. 운영자는 로컬 기록에 접근하거나 복구할 수 없습니다.

웹 호스팅과 외부 링크

정적 사이트는 GitHub Pages에서 제공합니다. 페이지를 요청할 때 IP 주소, 접속 정보 등 통신에 필요한 정보는 호스팅 제공자에게 전달될 수 있습니다. GitHub 개인정보 안내를 참고하세요. 외부 출처 링크를 클릭하면 해당 사이트의 데이터 처리 방식이 적용됩니다.

광고와 분석 코드

현재 공개 페이지는 광고 계정 식별용 메타 태그와 ads.txt만 제공합니다. Google AdSense 광고 로더, Google Analytics, Firebase 클라이언트 스크립트를 실행하지 않습니다. 광고·분석 기능을 추가하면 그 처리 범위와 동의 방식을 실제 구성에 맞게 갱신해야 합니다.

과거 커뮤니티 자료

이전 버전은 닉네임, 글·답글 본문, 작성 시각, PIN 해시, 투표와 브라우저 식별 관련 기록을 Firebase에 저장했습니다. 현재 공개 페이지는 해당 자료를 읽거나 새 글을 저장하지 않지만, 기존 서버 원본을 이번 개편에서 일괄 삭제한 것은 아닙니다. 서버 자료의 삭제·정정 요청은 운영 연락처로 문의할 수 있습니다. 브라우저 저장소를 지워도 과거 서버 글이 함께 삭제되지는 않습니다.

이메일 문의

이메일을 보내면 발신 주소와 문의 내용이 운영자 및 메일 서비스에 전달됩니다. 문의 확인과 답변을 위해 사용하며 비밀번호·인증 코드·결제 정보를 보내지 않도록 안내합니다. 메일 관련 삭제 요청도 같은 연락처로 보낼 수 있습니다.

방침 변경과 문의

서비스 동작이 바뀌면 적용일과 내용을 갱신합니다. 현재 안내와 실제 동작이 다른 부분을 발견한 경우 문의 페이지의 주소로 알려주세요.
